# Public repository boundaries

- Keep only application source, runnable examples, tests, usage instructions, and necessary functional screenshots public.
- Do not add WeChat article bodies, article source drafts, publication artwork, asset archives, or article generators. They remain local/private; link to the WeChat album instead.
- Code is Apache-2.0. Linked WeChat articles are separate works outside this license.
- Never commit API keys, personal knowledge, conversations, databases, private APKs, signing files, or build caches.
- PC and mobile clients only; no business backend or automatic cluster command execution.
- Learned model summaries remain unverified until reviewed by the user.
- Run npm test and npm run build in client, and python tools/check_public.py at the repository root. Use npm run test:ui for relevant UI changes.
